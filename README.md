# 🚀 Shubham Dubey - Personal Portfolio

Welcome to the repository for my personal portfolio website! This project serves as a digital resume and a showcase of my technical skills, educational background, and software development projects.

## 🌟 About the Project

As a B.Tech student in Computer Science and Engineering (Data Science), I built this portfolio to highlight my journey in software engineering, data analysis, and cloud-native architecture. The website is designed with a modern, cyber-industrial aesthetic, focusing on performance, clean code, and interactive user experiences.

### ✨ Key Features
*   **Modern UI/UX:** Features a sleek dark mode theme with neon teal and purple accents.
*   **Scroll Animations:** Utilizes the JavaScript `IntersectionObserver` API for smooth, staggered reveal animations as the user scrolls.
*   **Fully Responsive:** Built with CSS Flexbox and Grid to ensure a seamless experience across desktops, tablets, and mobile devices.
*   **Glassmorphism Design:** Employs frosted-glass effects on cards and the navigation bar for a premium feel.
*   **Continuous Animations:** Uses CSS Keyframes for subtle background pulsing and floating elements.

## 🛠️ Tech Stack

This project was built entirely from scratch using core web technologies to ensure maximum performance without relying on heavy frameworks:
*   **HTML5:** Semantic structuring for better accessibility and SEO.
*   **CSS3:** Custom properties (variables), Grid, Flexbox, Keyframe animations, and media queries.
*   **Vanilla JavaScript:** DOM manipulation and scroll-triggered events.
*   **FontAwesome:** Scalable vector icons for UI elements.
*   **Google Fonts:** Utilizing the 'Poppins' font family for clean typography.
